# Internet Speed Meter

An Android internet speed monitoring app built using Java and Gradle.

**Creator:** Soumen Roy

## Features

- Live upload and download speed monitoring
- Persistent notification showing network speed
- Start and stop controls
- Custom launcher icon
- Built on an Android phone using Termux

## Build requirements

- Android SDK 35
- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3

## Build

From the project root, run:

```bash
gradle assembleDebug --no-daemon
`app/build/outputs/apk/debug/app-debug.apk`
